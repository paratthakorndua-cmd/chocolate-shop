# 🍫 CHOCO CRAFT - ระบบร้านค้าช็อกโกแลตแท่ง & จัดการคลังแพ็คพัสดุ

โปรเจกต์เว็บไซต์ขายช็อกโกแลตแท่ง (2 SKUs) เชื่อมต่อฐานข้อมูล Google Sheets พร้อมระบบหลังบ้านสำหรับหยิบสินค้า แพ็ค และพิมพ์ใบจ่าหน้าพัสดุ

## 📁 โครงสร้างไฟล์ในโปรเจกต์
- `images/` : โฟลเดอร์เก็บรูปภาพสินค้า (`dark-choc.jpg`, `milk-choc.jpg`)
- `index.html` : หน้า Landing Page สำหรับลูกค้าสั่งซื้อสินค้า
- `admin.html` : หน้าสำหรับพนักงานหยิบสินค้า (Picking) ยืนยันการแพ็ค และพิมพ์ใบปะหน้าพัสดุ
- `config.js` : ไฟล์ตั้งค่าลิงก์เชื่อมต่อ Google Apps Script
- `Code.gs` : โค้ดสำหรับนำไปวางใน Google Apps Script

## 🚀 ขั้นตอนการติดตั้งและใช้งาน (ทำตาม 3 ขั้นตอน)

### ขั้นตอนที่ 1: ตั้งค่า Google Sheets & Apps Script
1. สร้าง Google Sheet ใหม่ ตั้งชื่อว่า `Chocolate_Orders`
2. ไปที่เมนู **ส่วนขยาย (Extensions) > Apps Script**
3. นำโค้ดทั้งหมดในไฟล์ `Code.gs` ไปวางแทนที่โค้ดเดิม แล้วกดบันทึก (Ctrl+S)
4. เลือกฟังก์ชัน `setupSheet` ด้านบน แล้วกดปุ่ม **เรียกใช้ (Run)** 1 ครั้ง (ระบบจะสร้างหัวตารางให้อัตโนมัติ)
5. กดปุ่ม **ทำให้ใช้งานได้ (Deploy) > การทำให้ใช้งานได้รายการใหม่ (New deployment)**
   - ประเภท: **เว็บแอป (Web app)**
   - ดำเนินการในฐานะ: **ฉัน (Me)**
   - ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน (Anyone)**
6. คัดลอก **Web App URL** ที่ได้

### ขั้นตอนที่ 2: เชื่อมต่อ URL และอัปโหลดขึ้น GitHub
1. เปิดไฟล์ `config.js` แล้วนำ Web App URL มาวางแทนที่ `YOUR_GOOGLE_SCRIPT_WEB_APP_URL`
2. สร้าง Repository ใหม่บน GitHub และอัปโหลดไฟล์ทั้งหมด (รวมโฟลเดอร์ `images/`) ขึ้นไป

### ขั้นตอนที่ 3: นำขึ้นโดเมนของ Vercel
1. เข้าเว็บไซต์ [vercel.com](https://vercel.com) ล็อกอินด้วย GitHub
2. กด **Add New... > Project** แล้วเลือก Repository ของโปรเจกต์นี้
3. กด **Deploy** รอประมาณ 30 วินาที จะได้ลิงก์ `.vercel.app` พร้อมใช้งานทันที
